# Starter companion assets

These three transparent PNG files are used only as the small companion shown beside the player character and in Weekly Battle:

- `bulbasaur.png`
- `charmander.png`
- `squirtle.png`

The companion UI uses fixed small dimensions and positioning so the artwork stays neat and consistent across player cards.

GymDex and the large starter-event artwork continue to use the existing full Pokémon image set.
